El Vagón Digital de la Convivencia

Digitalización

Modelo de educación deportiva

Cada grupo dispondrá de un blog de grupo para almacenar vídeos, documentos consultados, filmaciones, documentos generados, etc. Se puede utilizar WordPress (cómo crear un blog en Wordpress), Blogger (cómo crear un blog en blogger) o un sites.

A lo largo del proyecto crearemos una entrada para cada actividad que realice el grupo: vídeos, documentos, entrevistas, artículos de opinión, clasificaciones, etc....

En este momento, vamos a crear el blog y a hacer la entrada inicial:

Pensemos en un nombre atractivo para el blog.
Incluiremos la información básica:  el nombre de los componentes del equipo (con alguna imagen), el centro al que pertenecemos y la materia para la que creamos el blog o sites.
Crearemos una primera entrada de presentación general: explicaremos el proyecto que vamos a desarrollar (cuál es el objetivo final, sobre qué vamos a aprender) y enlazaremos el recurso que vamos a usar como referencia.
